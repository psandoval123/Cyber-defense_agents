# Contexto del proyecto

## Tema

Uso de agentes inteligentes en ciberdefensa para apoyar la detección y respuesta ante incidentes de seguridad.

## Propósito

Investigar, diseñar y documentar laboratorios reproducibles que permitan evaluar agentes inteligentes en escenarios controlados de ciberdefensa.

## Alcance inicial

- Detección de eventos de seguridad.
- Respuesta asistida y trazable.
- Threat hunting con fuentes controladas.
- Uso de herramientas open source.
- Despliegue reproducible mediante Docker Compose.
- Uso de datos sintéticos y ataques simulados no destructivos.

## Restricciones

- No se utilizarán ataques reales ni datos sensibles.
- Todo resultado deberá contar con evidencia: log, captura, notebook o script.
- Las decisiones técnicas se registrarán en ADRs.
- Los resultados no se considerarán válidos hasta ser reproducidos y verificados.

## Entregables principales

1. Documentación del contexto, metodología y evaluación.
2. Infraestructura aislada para los laboratorios.
3. Tres laboratorios: detección, respuesta y hunting.
4. Agentes de triage, respuesta y hunting.
5. Evidencias y métricas comparables.
6. Informe final.
